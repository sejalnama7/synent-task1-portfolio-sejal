🌐 Personal Portfolio Website

📌 Project Overview
This is a personal portfolio website created to showcase my profile, skills, and contact information. The project focuses on building a clean and responsive layout using basic web technologies.

🚀 Features
- Responsive design (mobile & desktop friendly)
- Clean and structured layout
- Sections included:
  - About Me
  - Skills
  - Contact Information

 🛠️ Technologies Used
- HTML5
- CSS3

 📂 Project Structure
- portfolio.html → Main structure of the website
- portfolio.css → Styling and layout design

 📖 Learning Outcomes
- Understanding of HTML structure and semantics
- CSS styling and layout techniques
- Designing user-friendly interfaces

 📌 Conclusion
This project helped me understand the basics of front-end development and how to structure a personal portfolio website effectively.
